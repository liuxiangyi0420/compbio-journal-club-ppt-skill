# 计算生物学组会文献讲解 PPT

目标是让课题组听懂这篇文章：为什么要做、为什么采用这个策略、每张图做了什么比较、结果说明什么。生成实际 PPTX，并为每页写可以自然讲出来的备注；另导出逐页 Markdown 讲稿。

## 开始前

阅读 [讲解与排版标准](references/teaching-standard.md)。计算生物学论文还需参考 [领域读图要点](references/compbio-reading.md)。[复用 prompt](references/reusable-prompt.md) 供不支持 skill 的环境使用。

默认中文、20–25 分钟，听众有本领域基础但未读过本文。用户指定的时长、受众和风格优先。页数与流程阶段根据新论文决定，参考文件的页数不固定套用。信息足够就直接制作，不默认要求逐页审批。

## 讲解原则

- 先阅读正文、图注和提供的补充材料，再按问题依赖组织讲解，不机械按图号排序。开头用一页流程图说明整篇研究如何一步步解决问题。
- 每页最上方一行写具体且有依据的结论句，副标题可写待回答的问题。
- 采用正文和图注的词义，翻译成自然中文。没有准确常用译法或容易混淆时保留英文，第一次出现解释，例如 self-consistency。不要用自造抽象名词包装结果。
- 正文帮助读图，备注解释为什么做、怎样做、怎样读图、结果意味着什么。讲稿不是正文的重复。
- 区分计算指标与实验结果、平均值与最佳样本、生成样本与筛选后的实验候选。逻辑重构不能冒充作者真实实验时间线。

## 视觉参考与工具

查看 `assets/reference.pptx` 中的实际排版和讲稿，`assets/preview.png` 为封面预览。保留参考文件不变；它只用于学习风格。新论文需要新的图表、结论和讲稿，不得残留参考论文的科学内容。

采用横向 16:9、白底、深蓝标题、青色强调，编辑文字和备注用微软雅黑。步骤编号用“1. 2. 3.”，不要“01、02”。来源放备注，不在页面添加 Source/resource 小字。原图内部字体保持原样，裁切保留必要坐标轴、标签和图例。

优先使用当前环境的 PPTX 制作工具与模板工作流。如果环境提供 Presentations 或相应技能，遵循其导入参考、制作、渲染和验证流程；其他环境使用可用的 PPTX 工具。本文档不附带商业字体或私有制作引擎，也不自动安装依赖。如无法生成 PPTX，应明确说明具体缺少什么，不能把大纲当成已完成文件。

## 交付检查

检查结论依据、术语、数字分母、图表可读性、备注完整性，以及溢出、遮挡和旧文献残留。渲染检查改动页面，修正发现的问题。交付真实 PPTX（全部备注）和逐页讲稿，保留必要来源。参考论文图表许可见仓库根目录 `THIRD_PARTY_NOTICES.md`。
