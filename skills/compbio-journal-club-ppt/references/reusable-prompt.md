> 请使用 $compbio-journal-club-ppt，把这篇文献和补充材料制作成中文组会 PPTX，并为每页写完整讲者备注。目标是把课题组讲懂。默认讲 20–25 分钟，沿用本 skill 的组会讲解风格；正文和图注中的术语优先，self-consistency 等不易准确翻译的词保留英文并解释。直接制作完整版本，附逐页讲稿。

如需改变时长或受众，在这句话后补充即可。下方是可以在其他对话或工具中使用的完整 prompt。

---

请阅读这篇论文的正文、图注和我提供的补充材料，为课题组制作一套完整中文 PPTX，并在每页写入可以自然讲出来的中文讲稿备注，另导出逐页 Markdown 讲稿。首要目标是让大家听懂作者为什么做、做了什么、怎样验证、结果说明什么。

默认汇报 20–25 分钟，听众有本领域基础，但没有读过这篇文章。页数按内容决定，可设少量备用页。信息足够就直接完成，不需要先让我逐页审批。

**讲解顺序**：按“提出问题 → 为什么采用这个策略 → 设计实验和对照 → 验证结果 → 解释机制或功能 → 推广与限制”组织，不机械按图号罗列。在开头用一页流程图说明整篇研究要一步步解决什么问题。根据论文重构研究思路时，明确是逻辑整理，不把推断当成真实实验时间线。

**标题和正文**：每页最上方一行是具体、准确的结论句。优先使用正文或图注的术语和句意，译成自然中文。没有准确常用译法或容易混淆时保留英文，首次出现用一句话解释。不要自造抽象说法，例如“贡献归因边界”“历史优选反馈”“共同赋能”。正文以帮助读图为主：比较谁与谁、轴和颜色是什么、关键结果在哪。保留重要数字及测量对象，区分计算预测与实验结果、平均值与最佳样本、筛选后命中率与全部样本成功率。

**备注**：不要只是重复正文。每页讲稿要解释当前问题、为什么做这个实验或对照、具体做了什么、图怎样读、结果意味着什么，并自然引到下一步。写成研究生向同组同学讲解的短段落，让人听一遍就能跟上。只解释理解结论必需的技术细节，复杂参数和公式可放备用页。重要限制具体说清，来源放备注末尾，注明主文及补充图表。

**排版**：横向 16:9，白底、深蓝结论标题、青色强调、深灰正文；可编辑文字和备注用微软雅黑。结论标题置于最上方，第二行可写具体问题，中部突出论文原图，底部一句直接要点。统一边距和对齐，图表尽量大且清晰。步骤编号用“1. 2. 3.”，不要“01、02”。不放 Source/resource 小字，来源全部留在备注；封面保留论文题目、作者、期刊、年份和 DOI。原图内字体不强行改，裁切保留必要的坐标轴、图例、面板字母和标签，不改数据。

**检查与交付**：核对正文和补充材料，检查标题有无夸大、术语是否一致、讲稿是否易懂、原图是否完整，以及文字溢出或重叠。交付真实 PPTX，包含完整讲者备注，同时交付逐页讲稿。不要仅交大纲或计划。
