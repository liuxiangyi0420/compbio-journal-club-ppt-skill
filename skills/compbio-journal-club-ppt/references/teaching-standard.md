# 组会文献讲解标准

## 目标与默认设置

首要目标是让课题组成员听懂这篇文章，能够解释作者为什么提出这个问题、为什么采用这个策略、每个实验比较了什么、结果解决了什么问题。不要把它做成结果摘要、术语清单或审稿意见汇总。

默认中文、20–25 分钟主讲，另设少量备用页。听众有本领域基础，但不假定他们已经读过这篇文献。根据论文长度和内容决定页数；参考文件的 20 页主讲和 7 页备用不是固定配额。用户给出时长、受众或新的要求时，以当次要求为准。信息足够就直接制作完整 PPTX，不默认要求逐页确认或先批准预览。

## 从文献到讲解顺序

1. 阅读正文、图注和用户提供的补充材料，先确认主张、关键实验、对照和测量指标。补充材料缺失时，利用已提供证据继续，不虚构其中内容。
2. 按“为什么要做 → 作者怎样做 → 怎样证明有效 → 结果怎样解释 → 还能用在哪里”组织。不要机械地按图号排序。
3. 用一页简洁流程图说明全文的探究过程。阶段数按论文实际内容决定，不强制六步。每一步说清要解决的具体问题，并在讲稿中对应证据图表。
4. 如果重构了作者可能的研究思路，明确这是依据论文整理的逻辑，不声称是团队真实实验时间线。保留原文明确交代的前后关系。
5. 每页只讲一个主要问题。主讲页保留理解主线所需内容；详细阈值、额外对照、公式和技术争议放在备注或备用页，除非它们对结论至关重要。

## 标题与正文：准确、具体、说人话

- 每页最上方一行是该页的结论句，包括封面、流程图和备用页。标题直接说明结果或方法做了什么，不只写“背景”“方法”“验证”。不要为了像结论而夸大证据。
- 副标题可说明这页要回答的具体问题或怎样读图。
- 优先采用正文和图注的概念、术语和句意，准确翻译、必要时缩写；不要机械逐字翻译长句，不使用自创抽象名词包装结果。
- 有准确、常用中文就用中文；没有合适译法或翻译容易混淆时保留英文，例如 self-consistency、neural proofreading。第一次使用时以一句通俗解释说明含义。模型名、分子名、指标名保持一致。
- 优先写明对象和动作，例如“用 RFAA 筛选，会错过这 5 个 Apixaban binder”。少用“支持能力”“共同赋能”“贡献归因边界”“序列与结构相容性指标”“历史优选反馈”等难懂的抽象表达。
- 结果页让原始图表承担主要证据，正文帮助读图：谁与谁比较、轴或颜色是什么、哪里体现主要结果。文字不要把图注完整抄上去。
- 必要的数字要说明对象和分母。例如区分平均恢复率与最佳样本，筛选后的实验命中率与全部生成序列的成功率，预测置信度与实验亲和力。
- 明确区分原文观察、作者解释和讲解中的推断。只保留会改变听众理解的限制，不让每页变成免责声明。

## 备注：写成可以自然讲出来的中文讲稿

每页都要有实质性 speaker notes，不能只重复标题和正文。默认按下面的顺序写成连贯的短段落，必要时调整：

1. 用上一页引出这一页的问题：“接下来作者想知道……”或直接说当前问题。
2. 解释作者做了什么、为什么需要这个实验或对照。交代理解结果必需的输入、输出和测量对象，不堆砌所有技术参数。
3. 带听众读图：“先看左图……横轴是……蓝色代表……比较这两组……”只描述图里实际存在的内容。
4. 说出主要结果及其含义。解释第一次出现的指标或术语，公式只有在帮助理解时才展开。
5. 如果有重要证据边界，用一句具体的话交代；最后自然接到下一步。无需每页机械套同样句式。

备注要像研究生向同组同学解释论文，保持科学准确，但让人听一遍就能跟上。不要使用“本页提供某层面的支持”“证据边界需分层判断”等抽象评述替代解释。默认每张主讲页约 1 分钟，方法核心或复杂结果可稍长，封面和流程页可更短；随总时长调整。来源放在备注末尾，注明 Fig./panel、补充图表或方法章节。

## 排版参考

保留本 skill 的 assets/reference.pptx 和 assets/preview.png 作为实际参考。参考文章的科学内容只用于观察风格，不能进入下一篇文献的结果。

- 横向 16:9，白色背景；深蓝标题、青色强调、深灰正文、灰色辅助文字。
- 可编辑文本及备注均用微软雅黑（Microsoft YaHei）。论文原图内部字体保持原样。
- 顶行结论标题左对齐；第二行可放问题或读图提示；中部以论文原图为主；底部用一句直接的结果或要点。保持稳定的左右边距和对齐。
- 数字步骤用“1. 2. 3.”，不使用“01、02”。页码用普通整数。
- 不出现页面左下角或其他位置的 Source/resource 小字。正文与图表来源留在 speaker notes，封面保留文章题目、作者、期刊、年份和 DOI。
- 按证据需要选择宽图、图与说明并排、两图比较、数据大字或原生表格。不要强行把所有页面做成同一种卡片布局。
- 原图尽量大且清晰。裁切保留必要的面板字母、坐标轴、图例、标签及尺度，不能改变数据。没有读图价值的整页缩小图应改为关键面板。

## 制作与检查

使用当前环境的演示文稿工具和模板工作流，沿用实际参考的视觉系统，生成真正的 PPTX。需要纸到 PPT 的证据组织帮助时，可以结合 nature-paper2ppt；本 skill 的排版和措辞偏好优先于它的默认设置。

交付前至少检查：所有页面的结论是否具体且有原文依据；核心术语是否一致；讲稿是否解释而不是重复；数字是否对应同一测量对象；原图是否完整可读；文字是否溢出或重叠；备注是否齐全；有无旧论文内容残留。渲染后检查改动页面，修正发现的布局问题，不以成功导出代替检查。

交付完整中文 PPTX（包含所有页的备注），并同步导出一份逐页 Markdown 讲稿供用户排练。用户要单页预览或逐页大纲时遵从，否则直接完成整套。保持辅助文件精简。

## 表述参考

这些例子来自用户认可的参考，只学习表达方式，不复制到新论文：

| 避免的表达 | 更容易懂的表达 |
|---|---|
| 历史优选反馈让序列与复合物几何共同调整 | NISE 反复设计序列、预测复合物，再选出下一轮输入 |
| 完整序列背景下的局部校对可提高亲和力 | 两个点突变将 EPIC 的亲和力提高了 100 倍 |
| 预测器的配体建模能力影响候选能否通过筛选 | 用 RFAA 筛选，会错过这 5 个 Apixaban binder |
| 实验分母与拟合条件决定结果的解释范围 | 4/4 和 5/6 指送去实验的设计，不是全部计算样本 |

最重要的自检：听众听完这一页，能不能用自己的话说明“作者做了什么、结果说明什么”？如果不能，继续改写。
